## 6. Engine facts relied on (new since Oct 30 handoff)

- The PoS solver (`survivalRatePro`) does no tax math; it tests balance survival only.
- Solver use: table yearly solve = full solve paths x binary iterations from that year's median balance (seed 999 + y*37 + seed); fan-path yearly re-check = max(20, solve/8) paths x min(iters, 10) (seed p*1000 + y*37 + seed).
- The GUI's Run uses seed 0 when Re-randomize is off.
- Final-years top-up window = last 5 plan years (TOPUP_YEARS); in Bob's plan every path that reached $0 did so inside it.
- The Money Mkt (total) reserve is available to top up a short year: always in the last 5 years, and earlier ones too when the Q21 box is checked.
- Bob's plan (detailed_accts test, 1200/600/23): about 32 of 600 paths stay short after the Money Mkt (range 22-43 over 12 seeds); about $123,000 (2027 $) more reserve would have covered all.
